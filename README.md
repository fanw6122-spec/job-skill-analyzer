# Job Skill Analyzer · 招聘岗位技能分析器

一个可以在 Windows 本地运行的招聘 CSV 数据分析小工具：上传数据、选择城市、点击“开始分析”，即可查看各城市的岗位数量以及技能需求。

**Tech stack:** Python 3.12 · Pandas · Streamlit · uv · unittest

这是 AI 应用开发学习第一周的原创练习项目，重点展示数据清洗、数据契约、分组统计、Web 表单交互、模块化与自动化测试；**不包含招聘网站爬虫，也不代表实时岗位市场分析**。

## 核心功能与示例

- 上传 UTF-8 CSV 文件，检查必需列并保留 `001` 一类带前导零的岗位编号。
- 删除城市或岗位名称缺失、只包含空格的无效记录。
- 基于实际文件动态生成城市选项，可选择“全部城市”或某个城市。
- 在点击“开始分析”后，分别显示全体城市岗位数量和所选城市技能统计。
- 对同一个岗位内重复出现的技能只计一次，不错误合并不同岗位。
- 对空文件、缺列和无有效记录给出清晰提示。

随项目提供的 `data/sample_jobs.csv`：原始 8 条，清洗后 4 条；选择深圳后得到 **Python=2、Agent=1**。

## Windows 一键使用

1. 解压整个 ZIP，保持所有文件相对位置不变。
2. 双击 `run_windows_acceptance.bat`，等待自动创建项目内的 `.venv` 并执行测试。
3. 双击 `run_windows_app.bat`，在浏览器打开本地界面（如未自动打开，请访问 `http://127.0.0.1:8501`）。
4. 点击“上传招聘 CSV 文件”，可直接选择本项目的 `data/sample_jobs.csv`。
5. 选择“深圳”或其他城市，点击“开始分析”，查看两个表格。
6. 返回命令窗口，按 `Ctrl+C` 停止服务。

仅使用 `uv` 管理 Python 3.12 及项目本地 `.venv`，不要求系统安装全局 Python。首次运行需要联网下载项目依赖。

## 设计与数据契约

- CSV 必需列：`岗位编号`、`城市`、`岗位名称`、`技能`。
- 输入文件使用 UTF-8（可有 BOM），`岗位编号` 保留前导零。
- 城市、岗位名称两列会去除前后空格，缺失或纯空格的行会被清理。
- 技能用**英文分号 `;`** 分隔；同一岗位重复的技能只计一次，不同岗位分别计数。
- 上传后先读取并校验文件，以生成正确的城市下拉选项；**统计必须等待“开始分析”提交**。
- 没上传文件、空 CSV、缺列或没有有效岗位时，页面显示明确提示，不伪装成统计结果 0。
- 页面不访问公网、不存储上传内容、不修改 CSV 文件，也不运行上传文件中的代码。
- V0.1 不启用数据缓存，避免文件内容变化后静默使用旧统计结果；缓存优化留待明确数据规模与更新频率后再做。

## 主要验收场景

| 场景 | 预期 |
| --- | --- |
| 使用 `data/sample_jobs.csv` | 8 条输入 -> 4 条有效岗位 |
| 选择“深圳”并提交 | 深圳 2 条岗位，Python=2、Agent=1 |
| 选择“全部城市”并提交 | 全部城市岗位数量 + 全部技能数量 |
| 缺少“城市”列 | 明确指出缺少必需列，不能产生统计表 |
| 上传空 CSV | 明确提示错误 |
| 改选城市但未提交 | 不执行统计，不出现新的统计表 |
