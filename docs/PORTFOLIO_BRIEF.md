# 作品介绍：Job Skill Analyzer

## 一句话介绍

使用 Python、Pandas 和 Streamlit 构建的本地岗位技能分析工具，将结构化招聘 CSV 转换成可交互的城市岗位数量与技能需求统计。

## 为什么做

求职者经常收集不同城市的招聘信息。直接统计原始 CSV 容易遇到空城市、空岗位名称、技能重复、岗位编号前导零丢失等问题。本工具用可验证的数据清洗规则处理这些情况，并用网页界面降低操作门槛。

## 最小使用流程

1. 上传 CSV。
2. 系统先验证输入并清洗记录。
3. 选择城市，点击“开始分析”。
4. 查看各城市岗位数量、所选城市的技能频次。

## 可向招聘方展示的技术能力

| 能力 | 项目内证据 |
| --- | --- |
| Pandas 数据处理 | 缺失与空格数据清理、`groupby().size()`、`split()`、`explode()`、岗位技能组合去重 |
| 数据契约 | 缺必需列时报错，不把输入错误伪装为零条岗位 |
| Python 模块化 | CSV 读取、清洗、统计、界面和集成服务分离 |
| Web 交互 | Streamlit 文件上传、动态城市选择、表单统一提交 |
| 自动化测试 | 原有 P02 12 项、P03 16 项、新增 12 项，总计 40 项 |
| 交付能力 | `uv.lock`、项目 `.venv`、Windows BAT、跨平台 GitHub Actions 配置 |

## 验证事实与边界

- 已有用户提供的 Windows 日志和截图确认示例数据的端到端操作成功。
- Linux 隔离环境中经过独立解压重装和 40 项复测；本作品展示包装完成后需再次复测。
- GitHub 工作流尚未在远程运行；不能宣称“CI 绿灯”。
- 不具备自动爬取真实岗位、技能语义归一、岗位去重（跨不同记录识别同一岗位）、大数据高性能和实时市场趋势能力。
- 项目开发由 AI 辅助，学习者完成需求、验证、解释和验收的实质参与。介绍时应如实说明协作方式。
